# 앱 개발 사례 설날카드

pxd 내부에서 UI디자인에 애자일 방법을 실험하던 팀 **Probetyping Labs**(현 Lean UX Lab의 전신)가 2013년 설 명절에 맞춰 출시한 연하장 앱 **설날카드**의 개발 후기다. 팀 이름의 'Probe'는 프로젝트 초기 단계부터 프로토타이핑으로 사용자 정보를 탐색(probe)한다는 취지를 담고 있으며, "실패에서 태어난 앱"이라는 자평이 이 프로젝트의 출발점을 압축한다. 직전에 만든 유아용 앱 **Amazing Kids Box**의 크리스마스 프로모션 페이지에 예상외로 많은 댓글과 좋아요가 달려 살펴봤더니, 사용자들이 홍보용 이미지를 실제 크리스마스 카드로 착각해 사용하고 있었다는 발견이 계기였다. 앱 홍보 자체는 실패했지만 사람들이 무엇에 반응하는지를 배우는 계기가 됐고, 팀은 이 관찰을 살려 유아용 앱의 사진 스티커 기능만 떼어낸 스핀오프로 한 달 안에 만들 수 있는 설날카드 앱을 기획했다(심의 기간까지 포함해 실제로는 2~3주 소요).

개발 방식은 기획·화면설계를 완료한 뒤 디자인·개발을 진행하는 일반적 순서 대신, 핵심 기능인 '얼굴 사진을 템플릿에 매칭시키는 기능'을 중심으로 **MVP(minimum viable product)** 프로토타입을 먼저 만들고 반복 개선하는 흐름으로 진행됐다. 이런 얼굴 합성형 앱에서 흔히 쓰는 방식은 카메라 미리보기 위에 템플릿을 겹쳐 놓고 피사체 위치를 맞춰 찍게 하는 UI인데, 단순하고 직관적인 반면 아이들을 대상으로 하면 문제가 컸다. 아이들은 가만히 있지 않아 위치를 맞추기 어렵고, 좋은 표정을 포착하기도 힘들었다. 전면 카메라로 화면을 보여주면 아이의 시선은 끌 수 있었지만, 카메라가 화면 옆에 달려 있다 보니 정작 촬영된 사진에서는 아이의 시선이 다른 곳을 향해 있는 문제가 새로 생겼다.

이 문제를 풀기 위해 팀은 촬영 버튼을 누르는 순간 미리보기를 없애고 카메라 렌즈 쪽으로 시선을 유도하는 애벌레 애니메이션(장난감을 흔드는 것과 같은 원리)을 시도하는 등 여러 프로토타입을 실험했다. 어느 정도 효과는 있었지만, 최종적으로는 **얼굴인식 기술**로 사진 속 얼굴의 위치와 크기를 자동으로 맞춰주는 방식을 택해, 사용자가 위치 조정이 아니라 좋은 표정을 얻는 데만 집중할 수 있게 했다. 기존 사진을 불러와 쓰는 경우에도 수동으로 리사이징·위치 조정을 해야 했던 번거로움을 같은 방식으로 해소했다. 사용자 테스트 피드백을 반영해 몇 차례 더 개선했지만, 명절 한 번만 쓰이는 시즌성 앱이라 실제 사용자 피드백을 지속적으로 얻기 어렵다는 한계는 팀 스스로도 인정하는 대목이다.

## 핵심 내용
- **Probetyping Labs**: 'Probe(안전한 실패)'를 통해 UI디자인에 애자일 방법을 도입하려던 pxd 내부 실험 팀, Lean UX Lab의 전신
- 계기: **Amazing Kids Box** 크리스마스 프로모션 이미지를 사용자들이 실제 카드로 착각해 반응한 것에서 얻은 인사이트
- 유아용 앱의 사진 스티커 기능을 떼어낸 스핀오프로, 심의 포함 2~3주 만에 개발
- 기획·설계 완료 후 개발하는 순서 대신, 핵심 기능(얼굴-템플릿 매칭) 중심 **MVP**를 먼저 만들고 반복 개선
- 카메라 미리보기+템플릿 오버레이 방식의 한계: 아이 사진 촬영 시 위치 맞추기·좋은 표정 포착의 어려움
- 전면 카메라 사용 시 카메라 위치와 화면 위치가 달라 시선이 어긋나는 문제 발생
- 애벌레 애니메이션으로 시선을 유도하는 프로토타입 실험 → 최종적으로 **얼굴인식 기술**로 위치·크기 자동 보정 채택
- 시즌 한정 앱이라는 특성상 반복적인 사용자 피드백 확보가 어렵다는 한계를 스스로 인정
