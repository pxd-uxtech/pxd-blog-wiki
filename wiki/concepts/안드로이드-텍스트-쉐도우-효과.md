# 안드로이드 텍스트 쉐도우 효과

**GUI 디자이너**가 포토샵 등 디자인 툴에서 손쉽게 적용하는 텍스트 그림자(**Text Shadow**) 효과는 실제 안드로이드 개발 코드로 옮기려면 별도의 구현이 필요하다는 문제의식에서 출발한 글이다. 필자는 해외 안드로이드 개발 블로그(styling android)의 자바 소스 포스팅을 인용해 텍스트 쉐도우를 구현하는 방법을 정리하고, 정확한 이해를 위해 원문을 함께 참고하도록 안내한다.

텍스트 쉐도우는 **네 가지 변수**로 제어된다. ① **Shadow Colour**(그림자 색상), ② **X Offset**(텍스트 대비 그림자의 수평 위치), ③ **Y Offset**(수직 위치), ④ **Radius**(그림자 가장자리의 블러 정도, 값이 클수록 흐려짐)이다. 이를 바탕으로 pxd의 GUI 가이드 문서 표기 방식도 함께 제시되는데, `Shadow Color="#000000"`(색상), `Shadow Radius="1.5"`(값이 높을수록 그림자 거리가 멀어짐), `Shadow Dx="3"`(1이면 우측, -1이면 좌측), `Shadow Dy="3"`(1이면 아래, -1이면 위), `Shadow Opacity="70%"`(그림자 불투명도)의 다섯 속성으로 정리해 개발자에게 전달할 수 있는 스펙 형식을 보여준다.

이 글은 짧은 코드 팁이지만, GUI 디자이너가 시각 효과를 개발 스펙으로 정확히 수치화해 전달해야 하는 실무 과제를 잘 보여주는 사례다. 포토샵 레이어 스타일의 그림자 효과(색상·거리·크기·불투명도)를 안드로이드 네이티브 파라미터(Color·Dx·Dy·Radius·Opacity)로 1:1 매핑함으로써, 디자인 툴과 개발 플랫폼 간 표현 격차를 줄이는 실용적 접근을 취한다.

## 핵심 내용
- **텍스트 쉐도우 4대 변수**: Shadow Colour(색상) · X Offset(수평 위치) · Y Offset(수직 위치) · Radius(블러 정도)
- pxd GUI 가이드 표기 예: `Shadow Color`, `Shadow Radius`, `Shadow Dx`(우:1/좌:-1), `Shadow Dy`(아래:1/위:-1), `Shadow Opacity`
- 디자인 툴(포토샵)의 레이어 스타일 그림자 효과를 안드로이드 자바 코드 파라미터로 매핑하는 실무적 접근
