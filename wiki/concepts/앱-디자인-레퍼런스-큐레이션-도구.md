# 앱 디자인 레퍼런스 큐레이션 도구

**GUI 디자이너**는 실제 작업에 들어가기 전 레퍼런스 조사를 위해 앱스토어에서 앱을 하나하나 검색·다운로드해 화면 디자인을 확인해야 했다. 위트스튜디오가 만든 **grappic**은 이런 번거로움 없이 앱스토어에 등록된 앱들의 GUI를 실시간으로 모아 볼 수 있게 한 크라우드소싱 큐레이션 서비스로, 2013년 pxd 블로그가 GUI 디자이너의 북마크 리스트에 추가할 만한 도구로 소개했다.

grappic의 구조는 세 화면으로 나뉜다. 메인 화면인 **Pic Board**는 유저 투표로 순위가 매겨진 추천 이미지를 먼저 노출해, 많은 사람이 선호하는 디자인을 우선 확인할 수 있게 한다. **Street**는 순위와 무관하게 이미지를 랜덤으로 보여주는 화면으로, 상하좌우 플리킹으로 가볍게 넘겨보며 출퇴근이나 자투리 시간에 캐주얼하게 둘러보는 용도에 적합하다. 마음에 든 이미지는 **My Pic**이라는 개인 라이브러리에 저장할 수 있는데, 기본 My Pic 외에도 사용자가 직접 pack을 새로 만들어 스타일별·장르별로 이미지를 분류해둘 수 있다. 즉 grappic은 단순 열람 도구가 아니라, 유저의 투표와 개인 아카이빙이 결합된 형태로 좋은 디자인이 자연스럽게 상위로 떠오르게 만드는 큐레이션 구조를 갖췄다.

당시 grappic은 앱과 웹사이트(베타) 두 형태로 운영됐는데, 모든 기능은 앱에서만 온전히 쓸 수 있었고 웹 베타 버전에서는 이미지 열람과 투표만 가능하고 My Pic 저장 기능은 지원되지 않았다. 이런 제약에도 불구하고 앱스토어 전체의 GUI 디자인을 한곳에서 훑어볼 수 있다는 점에서, 매번 개별 앱을 검색·설치해 참고하던 기존 방식보다 레퍼런스 리서치 효율을 크게 높인 사례로 소개됐다.

## 핵심 내용
- **grappic**(위트스튜디오): 앱스토어 등록 앱들의 GUI 디자인을 실시간으로 모아 보는 크라우드소싱 큐레이션 서비스
- **Pic Board**: 유저 투표로 순위가 매겨진 추천 이미지를 우선 노출하는 메인 화면
- **Street**: 순위와 무관한 랜덤 뷰, 플리킹으로 캐주얼하게 탐색하는 모드
- **My Pic**: 마음에 든 이미지를 저장하는 개인 라이브러리, pack 단위로 스타일·장르별 분류 가능
- 앱 버전은 전 기능 지원, 웹 베타 버전은 열람·투표만 가능하고 My Pic 저장은 불가
- GUI 디자이너가 앱스토어를 일일이 뒤지며 앱을 다운로드해 레퍼런스를 확인하던 번거로움을 해소하려는 목적
