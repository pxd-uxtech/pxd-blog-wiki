# Tech Planet 2012 컨퍼런스

**Tech Planet**은 SK Planet이 2012년 처음 개최한 IT 기술 컨퍼런스로, 인터컨티넨탈 서울 코엑스에서 열렸다. SK Planet 서진우 대표와 Google·Facebook 연사들의 키노트로 막을 올렸으며, 서 대표는 오픈 플랫폼의 가치를 강조하며 차별화 요소로 **빅데이터**와 **UX**를 꼽았다. pxd 참관기는 'UX의 발전 방향'을 주제로 한 세 세션 — Adaptive Path의 서비스 경험(SX) 세션, 고려대 이태일 교수의 Natural UI·제스처 세션, Sunnyloft 하경제 이사의 프라이빗 SNS 'Episode' 기획 세션 — 을 중심으로 후기를 남겼다.

**Adaptive Path**의 **재민 헤게만(Jamin Hegeman)**은 "From UX to SX(Service Experience)"에서 UX와 SX의 차이를 User Interface 대 Service Architecture, One-off 대 Ecosystem, Human 대 Human·System·Business, Tactical Experience 대 Strategical Experience로 대비하며, "**SX는 UX의 진화가 아니라 비즈니스와 서비스 디자인의 진화**"라고 정의했다. 서비스 디자인은 사람들이 그저 경험하게 놔두는 것이 아니라 경험과 시스템을 능동적으로 설계하는 작업이므로, 기존의 'Business Strategy → Planning → Projects → Design' 순서 대신 **'Service Design + Strategy → Planning → Projects → Design'**로 서비스 디자인이 비즈니스 전략 단계부터 결합돼야 한다고 주장했다. 이 세션에서는 Journey Map·Storyboard·Service Blueprint 같은 서비스 디자인 도구와, 헤게만이 공저한 『서비스 디자인 교과서』(원제 *This is Service Design Thinking*)도 함께 소개됐다.

고려대 산업디자인학과 **이태일** 교수는 "Natural UI: 새로운 UI의 가능성과 한계" 세션에서, 마우스·키보드 같은 전통적 인터랙션을 넘어 실제 세계와 디지털 세계를 더 매끄럽게(Seamlessly Intertwine) 연결하는 접점을 **Natural UI**로 정의했다. 새로운 인터랙션은 기술적 정확도가 떨어지거나 사용자가 낯설어하는 문제가 생기기 쉬운데, 닌텐도 Wii·Kinect의 성공 사례를 들어 제스처 디자인의 가능성을 설명했다. 학생들과 진행한 '소리 없이 제스처만으로 소통하는 Motion Drama', '제스처로 기능을 맞히는 Motion Speed Quiz' 같은 연구 활동도 소개했으며, 팜파일럿의 필기 인식 시스템 **Graffiti**(한 번의 필기로 글자를 인식시키는 Single-stroke shorthand handwriting recognition system)를 절충안의 예로 들어, 제스처가 주류 인터랙션이 되려면 기술적 장벽과 단가 제약을 극복할 절충점을 계속 찾아야 한다고 정리했다.

Sunnyloft **하경제** 이사는 프라이빗 SNS 서비스 '**Episode**'의 기획 스토리를 공유했다. 광고 노출, 네트워크 그루핑의 어려움, 프라이버시 침해, 군중 속의 고독, 데이터 과잉, 커뮤니케이션 채널 파편화 등 기존 SNS가 유발하는 스트레스에서 출발해, 관계 밀도가 깊고 그룹 단위로 시작한다는 점에서 기존 SNS와 차별화되는 **Private SNS** 성격의 Episode를 기획했다고 밝혔다. 경쟁 서비스 네이버 '밴드' 출시로 인한 어려움, Private SNS 특유의 낮은 확장성과 저조한 콘텐츠 생산으로 인한 이탈 문제를 해결하기 위해 가입 화면 요소를 최소화하고 튜토리얼을 제공해 이탈률을 낮췄으며, 위치 공유 기능 'I'm Here'·'Share Place', 그룹 사진 모아보기, 글자를 크게 보여주는 '버럭 채팅' 등 서비스 곳곳에 차별화 기능을 심었다고 소개했다.

## 핵심 내용
- **Tech Planet**: SK Planet이 2012년 처음 개최한 IT 기술 컨퍼런스, 빅데이터·UX를 핵심 키워드로 내세움
- Jamin Hegeman(Adaptive Path): "**SX는 UX의 진화가 아니라 비즈니스·서비스 디자인의 진화**", 서비스 디자인이 비즈니스 전략 단계부터 결합돼야 함
- 이태일(고려대): **Natural UI**를 실제 세계와 디지털 세계를 매끄럽게 연결하는 인터랙션으로 정의, Motion Drama·Motion Speed Quiz로 제스처 UI 연구
- 하경제(Sunnyloft): **Private SNS** 'Episode'는 기존 SNS 스트레스(프라이버시·데이터 과잉·채널 파편화)에 대응해 깊은 관계 밀도와 그룹 중심으로 설계
- 세 세션 모두 **UX를 넘어선 다음 단계**(서비스 경험·자연스러운 인터랙션·프라이빗 관계 설계)를 모색했다는 공통점
