# UI17 컨퍼런스와 회의 퍼실리테이션 기법

**UI17**(User Interface seventeen)은 미국 **UIE(User Interface Engineering)**가 주최하는 3일짜리 해외 컨퍼런스로, 학생보다는 현업 UX·UI 디자이너를 대상으로 세미나 발표와 풀데이 워크숍을 통해 정보 공유·업무 노하우·재교육을 목적으로 한다. 위승용(uxdragon)은 pxd의 근속자 해외 교육 제도로 2012년 11월 보스턴에서 열린 UI17에 참가했고, 이 페이지는 그의 참관기 중 둘째 날(Day-2)과 셋째 날(Day-3) 후기를 종합한다. 둘째 날은 8명의 강연자가 각 1시간 30분씩 요약 발표를 하고 주최자 **제라드 스풀**의 강연은 필수로 들어야 하는 방식으로 진행됐으며, 참가자는 총 9개 세션 중 5개를 골라 들을 수 있었다.

둘째 날 첫 세션은 **루크 로블르스키(Luke Wroblewski)**의 "First Person User Interface"였다. 천공카드 인터페이스에서 출발해 커맨드라인·GUI·**내추럴 유저 인터페이스(NUI)**를 거쳐, 아이폰·시리·엑스박스·리프모션(LEAP) 같은 사례로 이어지는 흐름 속에서 1인칭 시점으로 주변 공간을 내비게이팅하고 즉시 증강현실로 인식하며 근처의 사람·사물과 인터랙션하는 **First Person User Interface**라는 새로운 흐름을 소개했다. 발표 시점엔 이 흐름을 부를 확정된 이름조차 없을 만큼 막 태동하던 개념이었다. 이어진 **제라드 스풀(Jared Spool)**의 "The Secret Lives of Links"는 '링크를 잘 만들어라'는 메시지 하나로 강연 전체를 채웠다. 링크 디자인 원칙을 **피츠의 법칙(Fitts's Law)**과 연결지어 설명하면서, 사용자가 목표를 이루기 위해 어디를 클릭해야 하는지 알려주는 문구인 **트리거 워드(Trigger words)**를 잘 써야 하고, 사용자는 이를 스캐닝하다가 없으면 곧장 검색으로 전환한다고 강조했다. 또한 뒤로가기 버튼에 의존하거나 원하는 정보를 찾을 때까지 페이지를 들락거리는 **포고스티킹(Pogo-sticking)**을 유발하지 않도록, 링크는 밑줄 파란 텍스트처럼 다른 정보 요소와 구분되는 일관된 표기로 사용자의 기대를 충족시켜야 한다고 정리했다.

세 번째로 다룬 **네이선 커티스(Nathan Curtis)**의 "Fearless Prototyping for Sketches"는 8 Shapes(댄 브라운이 속한 회사)가 PDF·PPT 와이어프레임 대신 모듈화된 **HTML 프로토타이핑**으로 작업 방식을 전환해가는 흐름을 소개했다. 손 스케치를 먼저 그린 뒤 IPEVO 카메라·스탠드로 즉시 캡쳐해 HTML 프로토타입으로 옮기는 워크플로우와, 두 사람이 **드라이버(Driver)/옵저버(Observer)** 역할을 30분 간격으로 교대하며 짝을 이뤄 진행하는 **페어 프로그래밍** 방식이 함께 제시됐다. 발표의 요지는 와이어프레임을 그리는 데 시간을 낭비하지 말고 HTML을 배워 직접 프로토타이핑하라는 것이었으며, 필자는 이를 다른 세션에서 언급된 **Mobile First**(모바일 화면을 먼저 설계하고 큰 화면으로 확장하는 원칙)와 함께 소개했다.

셋째 날(Day-3)에는 **켈빈 호프먼(Kelvin Hoffman)**의 "Leading Epically Productive Meeting" 풀데이 워크숍이 진행됐다. 이 워크숍은 회의를 생산적으로 이끄는 **퍼실리테이션 기법**을 몸으로 익히도록 설계됐다. 참가자는 4개의 롤(역할)을 정해 돌아가며 체험한다. **퍼실리테이터**는 스위스처럼 중립을 지키며 아이디어를 평가하거나 기여하지 않고 프로세스만 코디네이팅한다. **레코더**는 그룹의 기억을 화이트보드 같은 공적인 자리에 조용하고 빠르게 기록한다. **그룹 멤버**는 아이디어에 적극 기여하되 방어적 태도 없이 긍정적인 상태를 유지한다. **리더**는 미팅을 설계하고 롤·참석자를 정하며 목표에 근접하도록 이끌되, 정작 회의 중에는 그룹의 한 구성원으로 녹아든다. 말을 하지 않고 결정하는 방식 등, 언성이 높아지거나 결정이 어려울 때 쓸 수 있는 대안적 의사결정 기법도 함께 소개됐다.

워크숍은 총 10개의 퍼실리테이션 기법을 하나의 흐름으로 엮어 진행됐다. ① **What's in the bag?**—마쉬멜로우·스파게티·테이프로 최대한 높은 탑을 쌓는 아이스브레이킹, ② **롤플레잉**—"어떻게 하면 미팅이 생산적/비생산적이 되는가" 같은 질문을 던지고 카드를 돌려가며 각자의 롤로 답하기, ③ 제품 만들기, ④ 문제 탐험하기(②와 동일한 롤플레잉 방식), ⑤ **아이디어 워크샵**—3~4명이 발표·크리틱을 거쳐 좋은 아이디어 2개를 추리고 1개로 좁히기, ⑥ **제품 이름 붙이기**—각자 다른 색 포스트잇으로 후보를 내고 결정하기, ⑦ **10 Second Gut-Check**—웹사이트를 10초씩 보고 10점 척도로 평가한 뒤 고/저득점 이유를 토론(짧은 시간이라 UI보다 GUI 평가에 적합), ⑧ **Sketch your user experience**—루크 로블르스키의 Mobile First처럼 모바일 화면을 먼저 스케치한 뒤 태블릿 화면으로 확장, ⑨ **PECHA KUCHA(페차쿠차)**—2003년 도쿄에서 건축가 마크 다이탐과 아스트리드 클라인이 시작한 발표 형식으로, 20장의 슬라이드를 각 20초씩 넘겨 총 6분 40초 안에 핵심 메시지를 전달하는 훈련, ⑩ **What's in the bag (REDUX)**—오늘 배운 것을 공유하며 마무리. 후기는 이 기법들을 게임스토밍(gogamestorm.com)의 퍼실리테이션 기법과 함께 참고할 것을 권한다.

## 핵심 내용
- **UI17**: UIE(User Interface Engineering) 주최, 현업 UX·UI 디자이너 대상 3일 컨퍼런스(세미나+풀데이 워크숍)
- 위승용(uxdragon)이 pxd 해외교육 제도로 2012년 11월 보스턴 UI17 참가, Day-2(선택 강연 5개)와 Day-3(퍼실리테이션 워크숍) 후기를 남김
- Day-2 · **루크 로블르스키**: "First Person User Interface" — 1인칭 시점의 공간 내비게이팅·증강현실·사물 인터랙션을 다루는 신흥 인터페이스 흐름
- Day-2 · **제라드 스풀**: "The Secret Lives of Links" — **피츠의 법칙**과 **트리거 워드**로 좋은 링크 디자인 원칙 제시, **포고스티킹** 유발 지양
- Day-2 · **네이선 커티스**: "Fearless Prototyping for Sketches" — 와이어프레임 대신 손 스케치→**HTML 프로토타이핑**, **드라이버/옵저버** 페어 프로그래밍 방식 소개
- Day-3 · 회의 퍼실리테이션 4대 롤: **퍼실리테이터**(중립·프로세스 관리) · **레코더**(그룹 기억 기록) · **그룹 멤버**(아이디어 기여) · **리더**(미팅 설계·목표 견인)
- 언성이 높아지거나 결정이 어려울 때는 말 없이 결정하는 대안적 의사결정 기법을 사용할 수 있음
- 10개 워크숍으로 구성된 퍼실리테이션 기법 세트: 아이스브레이킹(탑 쌓기) → 롤플레잉 → 제품 만들기 → 문제 탐험 → 아이디어 워크숍 → 네이밍 → 10초 평가(10 Second Gut-Check) → 모바일 퍼스트 스케치 → **페차쿠차(PECHA KUCHA)** → 마무리 공유
- **페차쿠차**: 2003년 도쿄에서 시작된 프레젠테이션 형식, 20장 슬라이드×20초=6분 40초로 핵심 메시지 전달을 훈련
- 게임스토밍(Gamestorming) 기법과 함께 참고할 것을 권장
