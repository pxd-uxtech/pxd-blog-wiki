# 제품 디자인 사례 — pxd 손목시계

2013년 GUI 디자이너 **limho**가 pxd 다이어리에 올린 짧은 글은 "언젠가 만들 수 있지 않을까"라는 마음으로 그려본 **pxd 기념품 손목시계 컨셉 스케치**를 소개한다. 실물 시계 제작은 요원해 보였지만, 사내 서비스 연구소인 **Lean UX Lab**이 이 컨셉을 실제로 작동하는 인터랙티브 웹 시계로 구현하면서 아이디어 스케치에 그치지 않고 체험 가능한 프로토타입으로 이어졌다.

이 시계 디자인의 핵심 콘셉트는 **pxd 로고 심볼이 매 시간 정각마다 완성되었다가 시간이 흐르며 다시 흐트러지는** 구조다. 12시 정각처럼 특정 시점에는 그래픽 요소가 모여 pxd 로고 심볼 형태를 이루고, "로고심볼의 완성을 위해 시간은 흐른다"는 문구처럼 시간이 지나며 그 형태가 풀어졌다가 한 시간마다 다시 조합되는 반복 구조를 갖는다. 시간을 표시하는 기능적 장치에 브랜드 아이덴티티를 시각적 서사로 결합한 시도다.

웹으로 구현된 프로토타입은 PC와 모바일 모두에서 동작하도록 만들어졌고, 모바일 화면에서는 사용자가 화면을 위아래로 드래그해 시곗바늘을 수동으로 돌려볼 수 있다가 손가락을 떼면 다시 현재 시각으로 복귀하는 인터랙션이 더해졌다. 실물 상품화 여부와 무관하게 아이디어 스케치를 곧바로 동작하는 웹 프로토타입으로 만들어 시각·인터랙션 완성도를 확인해보는 접근은, pxd 다이어리 시리즈에 반복적으로 등장하는 사내 제품·굿즈 아이디어 실험 문화의 한 단면을 보여준다.

## 핵심 내용
- 2013년 limho가 그려본 pxd 기념품 손목시계 컨셉 스케치, 실물 제작은 미정인 아이디어 단계
- 사내 서비스 연구소 Lean UX Lab이 컨셉을 실제 동작하는 인터랙티브 웹 시계로 구현
- 핵심 콘셉트: 매 시간 정각에 pxd 로고 심볼이 완성되었다가 시간이 흐르며 다시 흐트러지는 반복 구조
- 브랜드 로고를 시간 표시 기능과 결합한 시각적 스토리텔링 시도
- 모바일에서 화면을 드래그해 바늘을 수동 조작하고, 손을 떼면 현재 시각으로 복귀하는 인터랙션 구현
- 아이디어 스케치를 곧바로 웹 프로토타입으로 구현해 완성도를 확인하는 실험적 접근
