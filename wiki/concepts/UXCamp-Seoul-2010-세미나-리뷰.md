# UXCamp Seoul 2010 세미나 리뷰

**UXcampSeoul**은 2010년 2월 27일 서울대학교 멀티미디어 강의동에서 열린 비정기 UX 커뮤니티 컨퍼런스(바캠프 형식)로, pxd 위승용(uxdragon)이 자사 발표 소식을 정리해 공유한 글이다. 이 회차에서 pxd는 **한상택** 선임연구원이 "**Problem Driven Goal Directed Design, 아이폰 웹어플 리디자인**"이라는 제목으로 발표를 진행했다 — 문제 정의(Problem Driven)에서 출발해 **Goal-Directed Design** 방법론을 아이폰 웹 애플리케이션 리디자인 사례에 적용한 내용으로, pxd가 훗날 2014년 [[Cooper Visual Interface Design 워크숍]]을 정식 수강하기 이전부터 이미 이 방법론을 실무에 적용하고 커뮤니티에 발표해 온 이력을 보여준다.

글쓴이는 발표 자료(슬라이드셰어 임베드)와 함께, 앞서 열렸던 "1회 행사"의 발표자료 링크, 외부 블로그 "Are UX ready?"에 게재된 다른 참가자의 행사 후기 링크를 함께 소개하며 참고 자료를 정리했다.

## 핵심 내용
- **UXcampSeoul**: 2010년 2월 27일 서울대학교 멀티미디어 강의동에서 열린 바캠프 형식 UX 커뮤니티 행사
- pxd 발표: 한상택, "Problem Driven Goal Directed Design, 아이폰 웹어플 리디자인"
- 문제 정의(Problem Driven) 후 Goal-Directed Design 방법론을 적용한 아이폰 웹 애플리케이션 리디자인 사례
- pxd가 2010년부터 이미 Goal-Directed Design 방법론을 실무·커뮤니티 발표에 활용해 온 흐름을 보여주는 초기 기록
