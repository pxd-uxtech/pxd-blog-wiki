# GUI 디자인 사례 SKP Tcloud

**Tcloud**는 SK플래닛(SKP)이 2012년 4월 오픈한 **N-스크린(N-screen) 클라우드 스토리지 서비스**로, pxd는 이 프로젝트의 GUI 디자인을 담당했다. N-스크린 서비스의 핵심 특성상 하나의 저장소를 Web, Mobile Phone(iPhone·Android), iPad 등 서로 다른 디바이스에서 이어서 이용할 수 있어야 했고, pxd는 이들 대표 POC(Point of Contact)마다 각각 UI/GUI 디자인을 수행했다.

결과물은 서비스·비주얼 컨셉 정립부터 세부 화면 디자인까지 폭넓게 걸쳐 있다. 웹 애플리케이션 GUI와 페이지 메뉴 아이콘셋, 모바일 앱 런처 아이콘, 안드로이드 로딩 페이지, iOS 메인 메뉴 화면, 퀵메뉴, 스토리지 페이지, 모바일 스토리지용 아이콘셋 디자인 등이 포함되며, 작업은 2011년 가을부터 수개월에 걸쳐 진행됐다. 글은 pxd 내부 조직 구분을 보여주는데, GUI 디자인 결과물 정리는 **GUI Lab**이 맡고, 별도의 **UI Lab**이 UI 설계 관점의 프로젝트 리뷰를 후속으로 작성할 예정이라는 언급을 통해 당시 pxd가 프로젝트 산출물을 UI와 GUI 두 축으로 나눠 각 랩(Lab) 단위로 정리·공유했음을 알 수 있다.

이 글 자체는 완성된 화면 이미지를 나열하는 짧은 포트폴리오형 프로젝트 리뷰로, 디자인 과정이나 리서치 근거보다는 다양한 디바이스·폼팩터에 걸친 GUI 산출물의 일관성을 보여주는 데 초점을 둔다. 2012년 초 국내 통신사들이 N-스크린을 핵심 서비스 전략으로 내세우던 시기, 여러 디바이스에 흩어진 파편적 화면들을 하나의 통일된 GUI 언어로 묶어내는 작업이 실무에서 어떻게 이뤄졌는지 보여주는 사례다.

## 핵심 내용
- **Tcloud**: SK플래닛의 N-스크린 클라우드 스토리지 서비스, 2012년 4월 오픈
- 대상 플랫폼: Web, iPhone, Android, iPad — 디바이스별 POC마다 개별 GUI 디자인 수행
- 산출물: 서비스·비주얼 컨셉, 웹 GUI·아이콘셋, 모바일 런처 아이콘, 로딩·메인메뉴 화면, 퀵메뉴·스토리지 페이지 등
- pxd 내 **GUI Lab**과 **UI Lab**의 역할 분담 — GUI 결과물 정리와 UI 설계 리뷰를 별도로 작성
