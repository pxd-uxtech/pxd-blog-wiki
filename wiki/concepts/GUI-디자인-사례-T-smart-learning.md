# GUI 디자인 사례 T smart learning

**T smart learning(T 스마트러닝)**은 2010년 5월부터 2011년 11월까지 pxd, SK텔레콤, 청담러닝이 함께 진행한 프로젝트다. 중학교 2학년 학생을 타겟으로, 안드로이드 OS 기반 Tablet PC에 Launcher 형태로 제공되는 학습 Tool App과 학습 콘텐츠 제공 서비스로, 국내 최초의 Tablet PC 기반 스마트 교육 플랫폼이었다. 국내 대표적인 12개 교육사업체가 콘텐츠를 공급하는 형태로 설계됐다.

핵심은 여러 교육사에서 들어온 콘텐츠를 하나의 Launcher 안에 통합하는 방식이다. Launcher는 엄선된 학습 콘텐츠, 개인별 수준과 특성에 맞춘 학습관리, 학습 시 유용한 도구, 학습지원 커뮤니케이션을 한 화면에서 통합 제공하도록 설계됐다. 여러 이질적인 콘텐츠 제공사의 앱과 콘텐츠를 사용자 입장에서 하나의 일관된 경험으로 묶어내야 하는, 플랫폼형 교육 서비스 특유의 과제를 안고 있었다.

pxd는 Launcher 자체는 물론, Launcher에서 실행되는 15여 종의 학습 Tool App과 일부 학습 콘텐츠에 대해 마켓 리서치, 디자인 리서치, 사용자 인터뷰, UI 기획, 화면 UI 설계, GUI 디자인, GUI 가이드 작업까지 폭넓게 담당했다. 리서치부터 최종 GUI 가이드까지 이어지는 엔드투엔드 프로세스로 진행된 프로젝트였음을 보여준다.

마케팅 측면에서는 가수 싸이가 코믹한 교장선생님으로 등장하는 'T나게 재밌는 학교' TV 광고로 서비스를 알렸고, pxd는 디자인 작업 완료 시점에 맞춰 해외 출품을 위해 주요 메뉴를 영문화한 구동 데모 영상도 제작했다. 이는 국내 대표 통신사가 스마트 디바이스 초기 확산기에 태블릿 기반 교육 플랫폼을 해외 시장에도 선보이려 했던 시도의 일환으로 볼 수 있다.

## 핵심 내용
- **T smart learning**: pxd·SK텔레콤·청담러닝 협업 프로젝트 (2010.05~2011.11)
- 대상: 중2 학생, 안드로이드 Tablet PC 기반 Launcher형 학습 Tool App + 콘텐츠 서비스
- 국내 최초 Tablet PC 기반 스마트 교육 플랫폼, 12개 교육사업체가 콘텐츠 공급
- Launcher 기능: 학습 콘텐츠 큐레이션, 개인별 학습 관리, 학습 도구, 학습지원 커뮤니케이션 통합
- pxd 작업 범위: 마켓·디자인 리서치, 사용자 인터뷰, UI 기획·설계, GUI 디자인·가이드(Launcher + Tool App 15여 종 + 일부 콘텐츠)
- 가수 싸이 출연 'T나게 재밌는 학교' TV 광고, 해외 출품용 영문화 데모 영상 제작
